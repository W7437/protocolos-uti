# Repositório Protocolos UTI

Estrutura preparada para Cloudflare Workers Builds com:

- Root directory: `/`
- Deploy command: `npx wrangler deploy`

O `wrangler.toml` da raiz aponta automaticamente para `./ProtocolosUTI/site`.

## Atualizações futuras

Não mexa mais no Wrangler nem nas configurações do Cloudflare.
Para atualizar o site, substitua somente a pasta `ProtocolosUTI/` inteira.
