# Protocolos UTI

Aplicação web estática para organizar protocolos pessoais de UTI.

## Como abrir
Abra `index.html` no navegador.

## Recursos
- Cadastro, edição e exclusão de protocolos
- Categorias e tags
- Busca textual
- Favoritos
- Resumo rápido
- Campos para indicações, conduta, doses, alertas, monitorização e referências
- Armazenamento local via `localStorage`
- Exportação e importação de backup JSON
- Layout responsivo

## Privacidade
Nesta versão, os protocolos ficam armazenados apenas no navegador/dispositivo em que foram cadastrados.
Nenhum dado é enviado para servidor.

## Atenção
O sistema é uma ferramenta de organização pessoal. Protocolos clínicos devem ser conferidos com
diretrizes atualizadas, bula, referências institucionais e julgamento clínico antes do uso assistencial.
