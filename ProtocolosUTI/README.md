# Protocolos UTI

Estrutura pensada para facilitar as versões iniciais.

```text
ProtocolosUTI/
├─ site/
│  ├─ index.html
│  ├─ styles.css
│  └─ app.js
├─ package.json
├─ package-lock.json
├─ wrangler.toml
└─ README.md
```

Para trocar toda a interface, apague/substitua apenas a pasta `site/`.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Deploy
```bash
npm run deploy
```
